Como usar no Streamlabs

  1. Conecte este site à sua sala.
  2. Copie o link gerado em Fonte para transmissão.
  3. No Streamlabs/OBS, adicione uma Fonte do navegador com 1920 × 1080.
  4. Quando um jogador clicar no retrato da própria ficha, a imagem aparece automaticamente; um segundo clique oculta.

O site de controle e o link transparente são páginas separadas. Você pode fechar este painel depois de copiar a fonte: o overlay continua ouvindo a sala.
